# UX Profile

Generated by `setup-ui-ux-skills`. All UI/UX skills in this project read this file before changing layout, copy, or interaction.

Scope: the public site (`src/`, `public/`, `index.html` → hummapp.fi). The NAS web UI (`hummapp/app/templates`) may follow it too.

## Aesthetic reference

- **Standard:** Stripe
- **Notes:** Modern public infographic page. Refined typography, large tabular numerals for key figures, clear data visualisation, balanced depth (1px borders first, soft shadows < 0.08 alpha). Brand palette: navy `#1B325E` (structure, dark hero band), magenta `#C60651` (single interactive accent), sun yellow `#FDBE4F` (highlight only). Status colours are reserved for measurement states: green = good, amber = borderline, red = poor — always paired with an icon and a text label (KASE colours: green `#00A34D`, orange `#F89628`, brick `#A1342C`). Thresholds live in `src/thresholds.ts`.
- **Type:** KASE guide names Calibri (body) and Franklin Gothic Demi (headings). The web uses Libre Franklin for all UI at weights 400 / 500 / 600 only; min 12px (meta), 14–16px for content. Deviation from the guide (Calibri is not a web font) — confirm with KASE communications.
- **Text-safe brand colours on white:** navy `#1B325E`, petrol `#135367`, crimson `#C60651`, brick `#A1342C`, grays `#58595B` / `#6D6E71`. Never use gold `#FDBE4F`, light gold `#FFDCA3`, orange `#F89628`, sky `#C0E1F0`, pink `#F7B1CA` or gray `#939598` for text on white (contrast < 3:1). Green `#00A34D` only for marks and large text.
- **Brand illustrations:** the KASE folk-pattern illustrations (guide §6) are a brand element, not decoration slop; they may be used as a band (e.g. footer edge) from the official image bank files, never redrawn or recoloured.

## Banned anti-aesthetics

- Gratuitous glassmorphism / `backdrop-filter` without a high-contrast boundary
- Floating pastel pill badges for ordinary metadata (status chips with a text label are allowed)
- Arbitrary decorative gradients and neon glowing borders
- Multi-color radial rainbow gradients on standard CTAs
- Cartoon empty-state illustrations (people waving / high-fiving)
- Nested scrollbars and icon bloat inside inputs
- Charts with a truncated y-axis on bar charts (bars start at zero)
- Status colour without a text label

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** ≥ 4.5:1 for normal text, ≥ 3:1 for large text, borders and chart marks
- **Touch / focus:** 44×44px hit targets; visible `:focus-visible` ring (2px, offset 2px)

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Languages:** Finnish (default) and English (`?lang=en`, strings in `src/i18n.ts`). Data from the stable (horse descriptions, locations) stays in Finnish.
- **Notes:** Finnish, written for the general public: plain words, no internal jargon (no "staattinen tilannekuva", "vain luku"). Lead with what the number means for the horse.

## Icon library

- **Library:** Lucide
- **Package / path:** `lucide-react`
- **Notes:** One set only, 1.5–2px stroke, no emoji as UI icons.

## Agent rules

1. Read this profile before creating or editing any UI, CSS, or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout / chrome → `viewports`; forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library (or project SVG path). Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
5. Destructive actions always use an explicit confirmation dialog.
